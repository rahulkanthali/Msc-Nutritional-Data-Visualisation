# MSc Nutritional Data Visualisation

**MSc Data Analytics Dissertation | University of Portsmouth | 2026**

## Project Overview

This project explores how nutritional information can be presented through interactive data visualisations to help users understand and compare food products.

The project uses nutritional datasets sourced from Open Food Facts and Kaggle, with data preparation and analysis supporting the development of interactive Power BI dashboards.

## Tools and Technologies

- **Power BI:** Interactive dashboard development and data visualisation
- **SQL:** Data querying and analysis
- **Python:** Data preparation and transformation
- **Data Sources:** Open Food Facts and Kaggle

## Project Objectives

- Prepare and organise nutritional datasets for analysis.
- Explore nutritional information across food products.
- Develop interactive dashboards to communicate nutritional information clearly.
- Make nutritional data easier for non-technical users to interpret and compare.

## Dashboard Features

- Interactive visualisations of nutritional information
- Food product comparisons
- Dashboard layouts designed for desktop and mobile viewing
- Visual presentation of nutritional attributes to support interpretation



## Skills Demonstrated

- Data cleaning and transformation
- SQL and Python for data analysis
- Power BI dashboard development
- Data visualisation and storytelling
- Presenting analytical information to non-technical audiences

## Project Context

This project was developed as part of my MSc Data Analytics dissertation at the University of Portsmouth in 2026.
